# ☕ Java Console Applications

A collection of beginner-friendly console-based Java projects developed to practice Java programming concepts and improve problem-solving skills.

## 📂 Projects

### 1\. 🎯 Guess the Random Number

A simple number guessing game where the computer generates a random number between 1 and 10, and the user gets 3 attempts to guess it correctly.

**Features:**

- Generates a random number between 1 and 10.
- Provides 3 attempts to guess the number.
- Displays hints such as "Too High" and "Too Low".
- Displays a winning or losing message.
- Reveals the correct number at the end.

**Java Concepts Used:**

- Random Class
- Scanner Class
- For Loop
- If-Else Statements

### 2\. 🎮 Tic Tac Toe

A two-player console-based Tic Tac Toe game played on a 3×3 board using X and O.

**Features:**

- Two-player gameplay.
- Players take alternate turns.
- Displays a 3×3 game board.
- Validates row and column inputs.
- Prevents selecting already occupied positions.
- Checks winning conditions across rows, columns, and diagonals.
- Detects a draw when all positions are filled.

**Java Concepts Used:**

- 2D Arrays
- Scanner Class
- While Loop
- Conditional Statements
- Methods
- Static Variables
